Swagger-Tool is a Spring Boot REST API project developed for creating, testing, and documenting RESTful APIs using Swagger/OpenAPI.

Features

REST API development using Spring Boot

Swagger/OpenAPI API documentation

Easy API testing through Swagger UI

Request and response testing

Clean and structured backend architecture
